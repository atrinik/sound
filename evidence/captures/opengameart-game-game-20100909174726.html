Game-Game


Description:

 

This is the OST for a game that unfortunately has not been made. As the project is dead I release the music so that someone may find a use for it. The game was to be a oldschool 16-bit style space and planetary exploration themed platformer with some interesting ideas so I think the music will be appropriate for any such project.

Music was made in Guitar Pro 5 software and .gp5 and .mid files are available on my homepage (and also shell scripts to generate the ogg from midis).
